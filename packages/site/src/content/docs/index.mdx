`@sandlada/document-context` is a function-first IoC container and reactive state library hosted on
`HTMLElement` and physical DOM nodes. Independent bundles — Astro islands, micro-frontends, Web
Components — share services and state through the DOM tree itself, using the W3C Context Protocol.

## Why anchor to the DOM?

- **Space is scope.** Resolving a dependency walks up the DOM ancestor chain, so nested UI naturally inherits parent services with zero container boilerplate.
- **Zero-leak by construction.** Sessions live and die with their host node; disconnects are confirmed in a microtask and subscriptions are torn down automatically.
- **RxJS first-class.** State, lifecycle, and errors are available as RxJS observables (`state$`, `lifecycle$`, `errors$`, `session$`).
- **One bus for every framework.** React, Vue, Svelte, Lit, and vanilla scripts meet at native `HTMLElement` and W3C Context Protocol events — no shared module instance required.

## A complete example

```ts
import {
    createContext,
    defineToken,
    mount,
    pipe,
    provide,
    subscribe$,
    update,
} from '@sandlada/document-context'

interface CounterState {
    readonly count: number
}

interface CounterService {
    increment(): void
}

const counterToken = defineToken<CounterService>('public')('app:counter')

const blueprint = pipe(
    createContext<CounterState>({ count: 0 }),
    provide(counterToken, ({ session }) => ({
        increment: () => update<CounterState>((s) => ({ count: s.count + 1 }))(session),
    })),
)

const host = document.getElementById('app')!
const session = mount(blueprint)(host)
await session.ready

subscribe$<CounterState>((state) => {
    host.textContent = `Count: ${state.count}`
})(session)

update<CounterState>((s) => ({ count: s.count + 1 }))(session)
```

## What ships

- **Strict layering** — `domain` (zero DOM, zero I/O) ← `application` (composition root, session runtime) ← `infrastructure` (`dom`, `ssr`).
- **Two-phase purity** — Phase 1 blueprint composition has zero DOM, zero I/O, zero listeners.
- **Late-binding DI** — `inject`, `inject$`, `injectAll`, `injectAll$` over composed W3C Context Protocol events.
- **SSR-ready** — Per-request applications through `createSsrApplication()` with server placeholder hosts.

## Install

```bash
npm i @sandlada/document-context rxjs
```
