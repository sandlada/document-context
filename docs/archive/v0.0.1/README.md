# v0.0.1 historical documentation

These files describe the pre–v0.1.0 **feature-module** layout (`src/core`, `src/bridge`, `src/storage`, `src/dom`, `src/signals`) and APIs such as `withBridge`, `withStorage`, and `withProvider`.

The current library lives in [`packages/document-context`](../../../packages/document-context). Design and migration guides for v0.1.0 are in [`docs/next-version`](../../next-version/README.md).
